# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, credentials, access tokens, or private data in public issues.

Use GitHub's private vulnerability reporting / Security Advisories for this repository when available. Include the affected component, impact, reproduction conditions, and a proposed mitigation where possible.

## Scope

VRTc is currently in its architecture and specification phase. Security reports about planned features should clearly distinguish design concerns from vulnerabilities in implemented code.
